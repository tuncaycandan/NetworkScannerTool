# Network Scanner Tool v1.4.2

## Highlights

- Improved the main layout alignment across the network, range, search, view, density, theme, and language controls.
- Fixed vertical text alignment in buttons and centered the IP range separator.
- Fixed the `HTML Report` button wrapping onto two lines.
- Added quick device search across IP address, hostname, MAC address, vendor, device type, response, status, and network fields.
- Added list and card views for the device inventory.
- Added compact and normal density modes for displaying more devices at once.
- Added automatic column sizing and per-column show/hide controls.
- Added status-based row coloring for active, inactive, searching, and unknown devices.
- Added a collapsible details panel so the device list can expand toward the footer and restore with the up arrow.
- Fixed localized visibility of the `Columns` / `Sütunlar` and `Compact` / `Yoğun` controls.
- Preserved the standalone single-executable distribution model and the verified update flow.

## Installation

Download `NetworkScannerTool.exe` and run it on a supported Windows system. No additional resource folder is required.

## Compatibility

The application targets .NET Framework 4.8 and is intended for supported Windows systems. Existing v1.4 and v1.4.1 users can use the built-in update flow.
