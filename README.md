# Network Scanner Tool

Fast and lightweight network scanner for Windows.

Network Scanner Tool is a simple desktop application for discovering and analyzing devices on your local network.

## Features

- Fast parallel network scanning
- IP address and hostname detection
- MAC address detection
- Vendor / manufacturer identification
- Device type detection
- Open port scanning
- Network share scanning
- Ping and Traceroute
- HTTP / HTTPS access
- SSH support
- RDP connection
- Wake-on-LAN
- Scan history
- CSV export
- Device type filtering
- Turkish and English interface

## Requirements

- Windows 10 / Windows 11
- .NET Framework
- Administrator privileges may be required for some features
